Restricciones Duras

Evita colisiones físicas y lógicas. Garantiza que un profesor no dé dos clases a la vez, se respeten las capacidades de las aulas y las mallas curriculares no tengan solapamientos.

Optimización Blanda

Maximiza la calidad del horario. Minimiza los huecos para profesores, asigna aulas preferidas según la materia y balancea la carga diaria de los estudiantes.

Soberanía Local

Tus datos te pertenecen. Todo se almacena localmente usando SQLite, sin obligatoriedad de conexión a la nube ni telemetría forzada.

¿Necesitas reglas horarias personalizadas?

Las instituciones tienen necesidades únicas. Si requieres restricciones específicas para tu caso (ej. coordinadores con horarios especiales, rotación de laboratorios), abre un ticket detallando tu escenario.
